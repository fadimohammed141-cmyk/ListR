2. Commands

/addanime adds an anime using the required title, category, and episodes options. The available categories are completed, watching, and interested. An interested entry uses 0 episodes.

/animestats displays the user's anime lists.

/animereset modifies existing list data. Its reset-wat option determines whether all data, a category, a specific anime, or a specified number of episodes is affected.

When using /animereset with reset-wat set to episodes, a negative episode value adds episodes rather than removing them. Users are responsible for checking the value they enter before submitting the command.
